Site Data Editor
Privacy Policy

Last updated: 28 September 2026

In short: Site Data Editor does not collect, send, sell or share any data. Everything it reads or changes stays in your own browser.

What the extension does

Site Data Editor is a developer tool. When you open it (as a popup or in the browser's side panel), it shows the cookies, local storage and session storage of the website in your current tab, and lets you add, edit, copy and delete them. It can also add custom HTTP request headers that you define for a domain.

Data the extension accesses

  • Cookies of the website in the active tab, read and changed only while the extension is open.
  • Local storage and session storage of the website in the active tab, read and changed only while the extension is open.
  • Console messages of the website in the active tab (log, info, warning and error messages, and uncaught errors), recorded while the Console or Network tab is open. If you turn on "Capture from page load" for a site, recording also starts when pages of that site load, until you turn it off. Messages are kept in the page's memory and shown in the extension; they are gone when the page is closed or reloaded.
  • API calls (fetch and XMLHttpRequest) made by the website in the active tab, recorded while the Network tab is open or on sites where you turned on "Capture from page load": method, address, status and timing, and for failed calls also the response, the request payload and the headers. Like console messages, they stay in the page's memory and are shown only in the extension.
  • JavaScript you type in the Console tab, which runs on the page in the active tab, only when you run it.
  • The address of the active tab, used to know which website's data to show.
  • Custom header rules you create (domain, header name and value), saved in the extension's own browser storage on your device so they keep working.

What the extension does not do

  • It does not send any data to the developer or to any server. The extension makes no network requests of its own.
  • It does not use analytics, tracking, advertising or third-party services.
  • It does not sell, share or transfer data to anyone.
  • It does not read your browsing history or run on pages you do not open it on, except the sites you turn "Capture from page load" on for.

Clipboard

When you click a Copy button, the selected values are written to your clipboard. The extension never reads your clipboard.

Custom request headers

Headers you add are attached by your browser to requests going to the domain you chose, and only while the header is switched on. They are sent only to that website, as you configured.

Removing data

Delete any header rule from the Headers tab, or uninstall the extension to remove everything it has stored. Changes you made to a website's cookies or storage can be undone in the extension or in your browser's settings.
